    Causal Effects Without a Randomised Test: Synthetic Control, Modern Difference-in-Differences and Causal Discovery

    What to do when something was rolled out and nobody randomised it: build the missing comparison, avoid staggered-rollout bias, and know what causal discovery can claim.

    Contents

    The whole lesson in one sentenceWithout randomisation, a causal estimate is only as good as the comparison group you can defend.

    Part 1

    The intuition

    A bank launches a savings feature in Dubai only, and new accounts rise 14%. Did the feature cause it? You can't see what Dubai would have done without it. That unseen world is the counterfactual, and every causal method is a way of guessing it.

    Before-versus-after blames the feature for everything else that changed. Dubai-versus-Abu-Dhabi blames it for every permanent difference between the cities. Better is difference-in-differences (DiD): Dubai's change minus Abu Dhabi's change over the same months. Like judging a diet against a friend's over the same holiday season, only the extra change is yours.

    Hold onto thisWithout randomisation, each method trades it for an assumption. The skill is stating that assumption, showing evidence for it, and saying how wrong you would be if it fails.
    Part 2

    How it really works

    Difference-in-differences and parallel trends

    DiD removes anything constant per group and anything that hits both groups equally. Its one assumption is parallel trends: without the launch, the gap between the groups would have stayed stable. Levels need not match. You can't prove it about a world you can't see, only look for evidence against it.

    The standard check is an event study, which plots the gap in each period. Flat before launch is reassuring. Already drifting means DiD credits the drift to the feature, as Simulation 1 shows.

    A flat pre-trend is necessary, not sufficient: it can't catch a competitor promotion that starts at launch. Pre-trend tests are weak with a few noisy months, so plot the event study and reason about size. Cluster errors at the level treatment was assigned (branch, segment).

    Staggered rollouts and why the old regression breaks

    Programmes often reach branches at different dates. The habitual tool, a two-way fixed effects regression, equals DiD with one launch date but hides a problem with several: it quietly uses already-treated units as comparisons. If their effect is still growing, that growth is subtracted as if it were background, so the estimate can be too small or even wrongly signed.

    Modern estimators (Callaway and Sant'Anna, Sun and Abraham, imputation methods) compare only with untreated units. The trigger is staggered timing plus effects that grow with exposure, and the symptom is the old regression disagreeing with the event study.

    They fix the estimator, not the assumptions. You still need parallel trends, no anticipation (behaviour didn't change before launch) and no spill-over into the comparison units.

    Synthetic control

    With one treated unit and no good single comparison, synthetic control builds one: a weighted blend of untreated "donor" units, weighted so it tracked the treated unit before launch. After launch, the gap between the real and the blend is your estimate.

    The pre-launch fit is the diagnostic: if the blend can't reproduce the past, the post-launch gap means nothing. Inference is by placebo. Pretend each donor was treated and see how big a gap appears by chance. With 10 donors the smallest possible p-value is about 0.09, which is honest, not weak.

    Synthetic difference-in-differences blends both ideas and tolerates a constant level gap. Use it for few treated units; for many, use modern DiD.

    Causal discovery

    Everything above assumed you knew what causes what. Causal discovery asks which arrows are consistent with the data at all. Methods test conditional independences, search over graphs, or assume more about the mechanism. The key signature is the collider A → B ← C: A and C are independent but become dependent once you condition on B.

    The limit is fundamental. A chain, its reverse and a fork all imply the same independences, so they form a Markov equivalence class that no observational data can separate. Treat a discovered graph as a hypothesis generator, to test with an experiment or domain review.

    Language models that propose causal graphs

    An LLM has read a lot about how the world works, so given variable names it often proposes arrows an expert would accept. Treat it as a cheap source of prior knowledge. Good uses: draft a graph for experts to correct, suggest confounders, and forbid arrows that break time order.

    The risk is fluent but unverified answers. It recalls textbook links even where this bank's data disagrees, varies with wording, and cannot see unmeasured variables. Safe workflow: the model proposes, humans challenge each arrow, and anything that matters is checked against data or an experiment.

    Part 3

    How it fails, and how to spot it

    • A comparison group treated differently by design

      The rollout went to the busiest branches first, so untreated ones have different trends.

      Spot itAsk how rollout order was decided, and study the event plot.
    • Declaring parallel trends from a passed pre-test

      With few periods the test has almost no power.

      Spot itAsk for the event-study plot with confidence bands.
    • Two-way regression on a staggered rollout

      The coefficient is small or wrongly signed while the event study shows a clear rise.

      Spot itCompare with a modern estimate. A big gap means contamination.
    • Synthetic control with a poor pre-fit

      A large post-launch gap, but the blend never matched before launch.

      Spot itCheck pre-launch fit first, then the placebos.
    • Treating a discovered or LLM-proposed graph as a finding

      A tidy diagram gets read as the bank's causal structure.

      Spot itAsk which assumptions were used and which arrows come only from prior knowledge. Test the ones that matter.
    Part 4

    Self-check

    1. Why can't before-versus-after give a causal effect, and what does DiD add?

    Other things change over time too. DiD subtracts the comparison group's change, assuming the groups would have moved in parallel.

    2. A flat pre-launch event study: does that prove parallel trends?

    No. It shows no earlier drift, but can't rule out something that starts at launch.

    3. Why can a two-way regression give a negative effect when every unit benefited?

    It uses already-treated units as comparisons. If their effect is still growing, the later group's gain looks smaller.

    4. A synthetic control fits poorly before launch but shows a big post-launch gap. Strong evidence?

    No. Judge the gap against the pre-fit error and the placebos. Improve the fit first.

    5. Which of chain, fork and collider can observational data tell apart?

    Only the collider. The chain and fork imply the same independences, so time order or an experiment is needed.
