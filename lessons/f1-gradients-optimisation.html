    Gradient Descent: How Models Learn

    Part 1

    What gradient descent is

    In one sentenceGradient descent is how a model learns: it checks which way its error shrinks, takes a small step that way, and repeats until the error stops falling.

    Running example: you predict a house's price as price = w × area. The number w (AED per m²) is the setting the model must learn. Pick a value for w, and the average error on your known sales is some number. Try other values of w and you get the bowl above: one value of w gives the smallest error.

    The model cannot see the whole bowl. It only knows the error at its current w, and which way the ground slopes there. That is enough.

    Part 2

    Slope, gradient and the step

    • Derivative: the slope of the curve at one point. Steep and rising to the right means a large positive number. Flat means zero.
    • Gradient: the same idea when the model has many settings. It is a list of slopes, one per setting, and it points uphill. So the model steps the opposite way.
    • Learning rate: how big each step is. You choose it. It is the most important dial in training.

    How it differs from other ways to fit a model

    • Closed-form fitting (such as the formula for simple linear regression) jumps straight to the answer. It only works for simple models.
    • Gradient descent walks to the answer in small steps. It works for any model whose error you can measure, including neural networks with billions of settings.
    • Random search tries settings blindly. Gradient descent uses the slope, so it wastes far fewer tries.

    How it works

    1. Start with a guess for the settings (often random).
    2. Measure the error on the training data.
    3. Work out the gradient: which direction makes the error grow fastest.
    4. Move each setting a small step the opposite way: new setting = old setting − learning rate × slope.
    5. Repeat. Stop when the error stops improving.

    In a neural network, backpropagation is just the fast method for working out the gradient in step 3. It has its own lesson.

    Part 3

    The learning rate

    Too small and training crawls. Too large and each step overshoots the bottom. Slide it below to see both.

    How to read it

    • Loss curve falling smoothly: the learning rate is about right.
    • Loss curve falling very slowly: raise the learning rate.
    • Loss zig-zagging or rising: lower it, often by a factor of 3 to 10.
    • Loss flat but high: the model may be stuck, or too simple for the job.

    Real error surfaces are not one clean bowl. They have flat patches and small dips, so a ball can slow down or settle in a poor spot. In practice this rarely stops large networks from learning well.

    Smarter versions: momentum and Adam

    • Plain gradient descent: every step looks only at the slope right here.
    • Momentum: keeps some of the previous direction, like a heavy ball. It smooths zig-zags and rolls over small bumps.
    • Adam: adjusts the step size for each setting separately, using the recent history of its slopes. It needs less tuning and is the usual default for neural networks.

    All of them still do the same thing: step downhill.

    Show the formula

    new w = old w − learning rate × slope at old w. For error = w², the slope is 2w, so each step multiplies w by (1 − 2 × learning rate). For rates below 0.5 the factor is between 0 and 1, so w shrinks smoothly. Between 0.5 and 1 it is negative but small, so w flips side and still shrinks. Above 1 the factor is below −1, so w grows each step: that is divergence.

    Part 4

    Which optimiser to use

    MethodIdeaUse it when
    Plain gradient descentStep along the slopeLearning the idea, or small simple models
    SGD (stochastic)Slope from a small random batch of rows, so each step is cheapBig datasets (nearly every real model uses this form)
    SGD with momentumKeeps part of the last directionImage models, when you can afford to tune it
    AdamPer-setting step sizes plus momentumA safe default, especially for language models
    • Strong at: scaling to huge models, needing only a measurable error, and being simple to code.
    • Weak at: needing a sensible learning rate, and slowing down on flat regions of the error surface.

    In banking, every credit-scoring neural network and every fine-tuned language model is trained this way, so a training run that diverges or stalls is usually a learning-rate problem.

    Part 5

    Common mistakes and quick check

    • Learning rate left at the default

      Defaults suit typical cases only. If the loss misbehaves, try the learning rate first, before changing the model.

    • Unscaled features

      If salary is in thousands and age in tens, the bowl becomes a long narrow valley and steps zig-zag. Scale features first.

    • Stopping too early or too late

      Watch the error on held-out data as well as training data. If held-out error rises while training error falls, stop: the model is memorising.

    • Confusing the gradient with the step

      The gradient says which way and how steep. The learning rate decides how far to go.

    1. Why does the model step opposite to the gradient?

    The gradient points uphill, towards bigger error. We want smaller error, so we go the other way.

    2. Training error jumps up and down and then climbs. What is the first thing to try?

    Lower the learning rate. The steps are overshooting the bottom.

    3. What does the gradient tell you when a model has a million settings?

    A slope for each of the million settings, so one calculation says how to nudge all of them downhill together.

    4. What does momentum add to plain gradient descent?

    It remembers the previous direction, which smooths zig-zags and helps roll past small bumps.

    5. What is backpropagation?

    The fast way to compute the gradient in a neural network. Gradient descent then uses that gradient to take the step.
