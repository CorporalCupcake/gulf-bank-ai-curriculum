    CNNs and RNNs: Patterns in Images and Sequences

    Part 1

    What CNNs and RNNs are

    In one sentenceA CNN (convolutional neural network) slides a small pattern detector across a grid such as an image. An RNN (recurrent neural network) reads a sequence one step at a time, carrying a memory forward.

    Both are neural networks with a shortcut built in. The shortcut matches the shape of the data: a grid for the CNN, a line of steps for the RNN.

    The picture shows a tiny image: light on the left, dark on the right. The window is a small edge detector. Wherever it sits over the boundary, the matching cell of the feature map lights up.

    How they differ from a plain network

    • A plain network gives every input number its own weights and treats inputs as unrelated. A 100×100 image becomes 10,000 separate numbers, and the network has no idea which pixels are neighbours.
    • A CNN reuses the same small set of weights at every position. An edge is an edge wherever it appears, so it learns it once. That makes it far smaller and better at images.
    • An RNN reuses the same weights at every step of a sequence, and passes a memory from one step to the next. Order matters to it.
    • Gradient boosting on a table has no sense of space or order at all.
    Part 2

    How a CNN works

    Running example: telling a photo of a cat from a photo of a dog.

    1. Pick a filter. A filter is a small grid of weights, usually 3×3. One filter might respond to vertical edges, another to a patch of fur colour. The network learns them from data.
    2. Slide it across the image. At each position, multiply the filter's weights by the pixels underneath and add them up. That gives one number: how strongly the pattern is present there.
    3. Collect the numbers into a feature map. It is a new grid that says where the pattern was found. Use many filters and you get many feature maps.
    4. Shrink with pooling. Pooling keeps the strongest value in each small patch (typically 2×2). The map gets smaller and the result no longer cares about the exact pixel position.
    5. Stack the layers. The next layer looks for patterns in the feature maps, then the next, and so on.
    6. Finish with a normal layer. The last small network turns the patterns into "cat" or "dog".

    How to think about the layers

    • Early layers find simple things: edges, corners, colour blobs.
    • Middle layers combine them into parts: an eye, an ear, a patch of fur.
    • Late layers combine parts into whole objects: a cat's face.
    • A bright cell in a feature map means "this pattern is here". A dark cell means it is absent. A negative value means the opposite pattern.
    • Each layer sees more. A 3×3 window in layer 1 sees 9 pixels. By layer 5, one cell reflects a patch of the image tens of pixels wide.

    A 3×3 filter has only 9 weights, however big the image is. That is why CNNs can handle photos with millions of pixels.

    Part 3

    How an RNN works

    Running example: a café wants to guess tomorrow's sales from the last few days.

    It is one box, used again and again. The picture shows it "unrolled" so you can see each day.

    1. Read the first day. The box takes Monday's sales and a blank memory.
    2. Update the memory. It mixes the new day with the old memory into a new memory: a short list of numbers summarising everything so far.
    3. Make a guess from that memory if one is needed.
    4. Pass the memory on to the next day, and repeat with the same weights.

    How to read it, and where it struggles

    • The memory (the "hidden state") is the whole story so far, squeezed into a fixed-size list of numbers. Nothing else carries over.
    • Long sequences are hard. After 200 steps the early days have been squeezed and re-squeezed, and their signal has faded. Training also struggles to pass learning back that far (the "vanishing gradient" problem).
    • LSTM and GRU are upgraded RNNs. They add "gates", small switches that decide what to keep, what to forget and what to output. They remember much longer than a basic RNN.
    • It is slow to train. Day 3 cannot be processed until day 2 is done, so the work cannot be spread over many chips at once.

    This last point is a big reason that attention-based models (the next lesson) have taken over most sequence work, including text.

    Part 4

    Which to use

    ModelBuilt forStrong atWeak at
    CNNGrids: images, scans, spectrogramsSpotting local patterns anywhere; small and fastNeeds lots of examples; sees little of the "big picture" early on
    RNN / LSTM / GRUSequences: sensor data, short time seriesSmall, runs on a stream one step at a timeForgets over long ranges; slow to train
    TransformerText, and increasingly everythingLong-range links; trains in parallelCostly on very long inputs
    Gradient boostingTablesBest first try on spreadsheet dataNo sense of space or order

    CNNs are strong at: images, scanned documents (such as cheques and ID cards), and anything where "the same pattern can appear anywhere". They are weak at: relating two distant parts of an input, and at data with no grid shape.

    RNNs are strong at: streams that must be processed as they arrive, on small devices. They are weak at: long memory and parallel training.

    In practice: for images, start with a pretrained CNN and adjust it to your task. For text, use a transformer. Reach for an LSTM or GRU only for small streaming problems. For a plain table, use boosting.

    Show the formula

    One RNN step: new memory = squash(weights × today's input + weights × yesterday's memory). "Squash" is a function (often tanh) that keeps values between −1 and 1. The same weights are used at every step.

    In banking, CNNs read scanned cheques, ID documents and signatures, while sequence models look at a customer's transactions in order to spot fraud.

    Part 5

    Common mistakes and quick check

    • Using a plain network on images

      It ignores which pixels are neighbours and needs far more weights. A CNN is the better start.

    • Training a CNN from scratch on a small set

      With a few hundred images it will memorise them. Start from a pretrained CNN and adjust it.

    • Expecting a basic RNN to remember a long history

      Its memory fades. Use an LSTM, GRU or a transformer, or give it summary features of the long past.

    • Shuffling time series before splitting

      Train on the past and test on the future. A random split lets the model peek at the future.

    1. Why does a CNN need far fewer weights than a plain network on an image?

    It reuses one small filter at every position, instead of giving every pixel its own weights.

    2. What does a bright cell in a feature map mean?

    The pattern that filter looks for was found at that spot in the image.

    3. What is the "memory" in an RNN?

    A fixed-size list of numbers summarising everything read so far, passed from each step to the next.

    4. Why are RNNs slow to train?

    Each step needs the one before it, so the steps cannot run side by side.

    5. You must classify scanned ID cards. Which model do you start with?

    A pretrained CNN, adjusted on your own labelled scans.
