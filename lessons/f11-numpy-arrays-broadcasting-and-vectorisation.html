    F3.5 Day one ★ Priority About 8 minutes

    Python Data Tools: NumPy, pandas, Dates and Plotting

    Part 1

    The toolkit in one picture

    In one sentenceNumPy does fast maths on whole blocks of numbers, pandas puts labelled tables on top of it, and matplotlib and seaborn draw the result. Work on the whole column at once, never row by row.

    Our running example is a café's daily sales: one row per day.

    Part 2

    NumPy: whole-column maths

    In one sentenceA NumPy array is a tray of same-type numbers, and an operation on it runs on every item in one fast step. This is called vectorisation.

    Example: to add 5% tax to a million takings figures, a loop handles one number per pass. takings * 1.05 does the lot at once, often 50 times faster or more.

    Shape and broadcasting

    • Shape is the size along each axis. A table of 365 days by 4 drinks has shape (365, 4).
    • Broadcasting stretches a small array to fit a big one. Subtract the 4 average drink sales (shape (4,)) from the table and each column shifts by its own average.
    • The rule: shapes are lined up from the right, and each pair must be equal or one of them must be 1.

    Two quirks: a slice is a view, so changing it changes the original (use .copy()). And floats are inexact, so keep exact money as whole integers.

    Part 3

    pandas: tables with labels

    In one sentenceA pandas DataFrame is a table whose columns can each hold a different type, with labels on the rows and columns.

    Unlike a NumPy array, it holds text and dates too. Unlike a spreadsheet, it is scripted and repeatable. The labels bring silent traps that give wrong numbers without an error.

    • Alignment by label. a - b matches rows by index label, not position. Labels with no partner give NaN (missing). Using .values skips matching and can pair the wrong rows silently.
    • Joins multiply rows. merge is SQL's JOIN. If a key repeats on one side, matched rows double and so do totals. Pass validate="m:1" so it fails loudly.
    Part 4

    Dates and time zones

    In one sentenceTurn date strings into real datetimes, then make sure every value uses only what was known at that moment.
    1. Parse with an explicit format: "03/04/2026" means different days in London and New York.
    2. Resample to change the grain, such as receipts into daily totals.
    3. Roll to keep the grain and look back: rolling("7D").mean() is a running 7-day average of café sales.
    4. Check the window direction. Windows look backwards by default. center=True averages days that have not happened yet, so use it for a smooth chart, never for a feature or alert.
    5. Fix the time zone. Store UTC and convert to local time for day-based features. Dubai is UTC+4, so a UTC server files a 01:30 Dubai purchase under the previous day.
    6. Join by time with merge_asof, which takes the latest value at or before the event.
    Part 5

    scikit-learn pipelines: no peeking

    In one sentenceA Pipeline chains your preparation steps and model into one object, so every step learns only from the training rows.

    Preparation steps have fit, which learns from data, and transform, which applies what was learned. Calling fit on all rows lets the test rows influence preparation. That is leakage: the score looks better than reality.

    • Mixed columns: ColumnTransformer sends numbers and categories through different steps.
    • Save the pipeline, not the bare model.
    Part 6

    Plotting: honest charts

    In one sentenceMatplotlib is the engine and seaborn is the driver: seaborn takes a DataFrame and column names, and draws through matplotlib.

    Create the canvas explicitly (fig, ax = plt.subplots()) rather than relying on bare plt.plot(), and pass ax=ax to seaborn. Let the question choose the chart.

    In banking, check row counts and totals after every join, and keep day boundaries in local time.

    Part 7

    Common mistakes and quick check

    • Looping over DataFrame rows

      It is slow. There is almost always a one-line column operation.

    • Trusting a join without counting

      A repeated key doubles rows and totals with no warning. Compare row counts and totals before and after.

    • Preparing data before the split

      Selecting features or scaling on all rows leaks the test set into training. Put every step in a pipeline.

    • Centred windows and UTC days

      Both quietly use information from the wrong time. Use trailing windows and local-time days.

    1. Why is df["x"] * 2 better than a loop?

    It runs compiled code on the whole column at once, which is far faster on large data.

    2. After a merge, rows rise from 8 to 11. What is the likely cause?

    A key repeats in one table. Check for duplicates and use validate="m:1".

    3. Why must a scaler be fitted on training rows only?

    Otherwise it learns from the test rows, and the test score is no longer an honest guide to new data.

    4. A bar chart's axis starts at 90. What is wrong?

    Bar length no longer matches value, so small gaps look huge. Start at zero.

    5. What does merge_asof do?

    It attaches the latest value at or before each event, so no future information leaks in.
